## 4. PLAN DE MVP (Minimum Viable Product)

### **Fase 1 - MVP Core** (4-6 semanas)
**Objetivo:** Sistema funcional básico para registro y visualización de finanzas

1. ✅ Registro manual de transacciones (ingresos/egresos)
   - Formulario completo con validaciones
   - CRUD de transacciones
   
2. ✅ Sistema básico de categorías
   - Categorías predefinidas
   - Asignación a transacciones
   
3. ✅ Dashboard simple
   - Balance total
   - Últimas transacciones
   - Gráfico básico de ingresos vs egresos
   
4. ✅ Soporte multi-moneda básico
   - Registro en DOP/USD/EUR
   - Conversión manual de tasas
   
5. ✅ Presupuesto mensual por categoría
   - Definición de límites
   - Indicador visual de consumo
   
6. ✅ Exportación a CSV
   - Exportación básica de transacciones

**Entregables Fase 1:**
- Base de datos diseñada e implementada
- API REST funcional para transacciones
- Interfaz web responsive
- Sistema de autenticación básico

---

### **Fase 2 - Expansión** (4-6 semanas)
**Objetivo:** Funcionalidades avanzadas de gestión y análisis

7. ✅ Importación de estados de cuenta
   - Parser de CSV bancarios
   - Reconciliación automática
   
8. ✅ Módulo de metas de ahorro
   - Definición de metas
   - Tracking de progreso
   - Calculadora de ahorro
   
9. ✅ Reportes avanzados
   - Comparativas temporales
   - Gráficos de distribución
   - Análisis de tendencias
   
10. ✅ Detalle de transacciones (items)
    - Desglose de compras
    - Categorización individual de items

**Entregables Fase 2:**
- Sistema de importación robusto
- Dashboard expandido con reportes
- Módulo de ahorros completamente funcional

---

### **Fase 3 - Inteligencia** (4-6 semanas)
**Objetivo:** Capacidades de IA y automatización

11. ✅ OCR para facturas
    - Integración con Ollama + modelo de visión
    - Extracción automática de datos
    
12. ✅ Categorización automática con ML
    - Entrenamiento con datos históricos
    - Sugerencias inteligentes
    
13. ✅ Predicciones y análisis avanzado
    - Proyecciones de gasto
    - Detección de anomalías
    - Identificación de patrones
    
14. ✅ Chatbot financiero
    - Consultas en lenguaje natural
    - Respuestas basadas en datos reales

**Entregables Fase 3:**
- Sistema OCR operativo
- Modelos ML entrenados y en producción
- Chatbot integrado en la interfaz
