MainLayout manages:
  • isSidebarCollapsed (boolean) - Desktop sidebar state
  • isMobileSidebarOpen (boolean) - Mobile sidebar visibility

Passed to:
  • Sidebar (all states + handlers)
  • TopBar (onMenuClick, isSidebarCollapsed)

Updates on:
  • Desktop toggle button click → toggleSidebar()
  • Mobile menu button click → toggleMobileSidebar()
  • Mobile backdrop click → closeMobileSidebar()
  • Mobile menu item click → closeMobileSidebar()
